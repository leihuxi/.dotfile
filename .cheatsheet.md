# Terminal cheatsheet   (run `cheat` any time, or press prefix ?)

## Ghostty
Cmd+T new tab | Cmd+D / Cmd+Shift+D split right / down | Cmd+K clear | Cmd+, open config
Ctrl+`           global drop-down terminal (first time: allow Ghostty in Settings > Privacy > Accessibility)
Left Option = Alt (needed for Alt-c, Alt-. etc.)
Colours follow macOS light/dark: Catppuccin Mocha / Latte (tmux, nvim and prompt switch live; fzf and
syntax highlighting switch in new shells). Font: JetBrains Maple Mono (Chinese is exactly 2 columns)

## tmux   prefix = Ctrl-a (switches the IME to English first, so WeType can't swallow the next key)
t                attach/create session main (zsh)       tm [name]  pick/create a session with fzf
C-h/j/k/l        move between panes (no prefix; shared with vim splits)
prefix | \ _     split side by side    prefix -       split top/bottom (both keep the current dir)
prefix C-h / C-l previous / next window (repeatable)
prefix H/J/K/L   resize pane           prefix z       zoom / unzoom pane
prefix ?         this cheatsheet in a popup (q quits)  prefix /   list every tmux key
prefix c         new window            prefix 1..9    go to window     prefix Tab  last window
prefix s  ★      sessions / projects: sessions + frequent dirs + git repos; picking a dir creates a session (ts in zsh)
prefix g  ★      lazygit popup
prefix w  ★      scratch floating terminal in the current dir (the old s / w session & window lists are now S / W)
prefix u  ★      pick a URL on screen with fzf and open it
prefix t  ★      thumbs: hint letters on screen text; lowercase = copy, uppercase = copy and paste
prefix v  ★      extrakto: fzf over paths / URLs / words on screen; Enter copies, Tab inserts into the prompt
prefix o  ★      floax: persistent floating terminal (press again to hide, content kept); prefix N = float menu
prefix i  ★      btop system monitor popup (hjkl move, f filter processes, q quit)
prefix B  ★      gh-dash: my PRs / review requests / issues / CI (only this repo inside a repo; ? for keys); ghd in zsh
tab flag 󰚩       Claude in that window is waiting for you (clears when you switch to it)
status-right 󰚩   Claude 5-hour block usage / time left / burn rate / today
prefix [ / Enter copy mode: v select, C-v block, y copy to the system clipboard, / search
prefix m         toggle mouse          prefix e       edit tmux config    prefix r  reload config
prefix C-s / C-r save / restore sessions (also auto-saved every 15 min and restored on start)
prefix I / U     install / update plugins

## zsh
Tab              fzf completion with preview (< > switch groups)
-> or Ctrl-Space accept the whole grey suggestion        Ctrl-f  accept one word
Up Down / C-p C-n history search by the typed prefix
Ctrl-r           atuin history search (dir / duration / exit code; Ctrl-r again cycles global / session / dir)
Ctrl-t           pick files into the prompt with fzf      Alt-c   pick a directory and cd into it
Ctrl-g + key     fzf-git: f changed files  b branches  h commits  s stash  t tags  r remotes  l reflog  w worktrees  ? help
Alt-.            insert the last argument of the previous command     Alt-l  clear screen
fuck             fix the previous mistyped command (Up/Down to choose, Enter to run)
Tab              argument completion with descriptions (carapace, thousands of commands)
Esc Esc          prefix the current/previous command with sudo     Esc vv or Ctrl-x Ctrl-e  edit the command in nvim
Esc              vi normal mode (block cursor)
y                yazi file manager (hjkl browse, Enter open, q quits and cds to the current dir)
z <keyword>      jump to a frequent dir      zi  interactive      wd add / wd <name>  directory bookmarks
**<Tab>          e.g. vim **<Tab>, cd **<Tab>, kill **<Tab> pick with fzf

## Everyday commands
ll / la / lt     list / with hidden / tree      ccat file  highlighted view      lg  lazygit
fe  pick a file to edit    vg <word>  search contents and open at the line    fcd  cd into a subdir    fdr  cd up
fh  pick a command from history    fkill  pick processes to kill
fbr switch branch   fco switch branch/tag   fshow browse commits   fcs print a commit sha   fstash manage stashes
help <cmd>       tldr summary             reload  reload zsh
proxy on / off   toggle the proxy for this shell (no argument = show; new shells start with it on)
btop             system monitor           dust [dir]  what takes the space (tree)     duf  disk usage
mdv [file/dir]   render markdown with glow (a dir lets you browse)    cheat / prefix ?  also use glow

## Claude Code
cw [name]        parallel Claude: new git worktree + its own tmux session (no clashing edits)
,ac / ,aC        Claude inside nvim / continue the last conversation; visual ,as sends the selection, ,ab adds the file
,aa / ,ad        accept / reject Claude's proposed edit (reviewed as an nvim diff); a tmux Claude can attach with /ide
after restart    when tmux restores, panes that ran Claude run claude --continue
waiting          tab flag 󰚩 + bell; also a macOS notification (Ghostty) when you're not on that window
auto-format      after Claude edits a file: rustfmt / ruff / shfmt / stylua; prettier only with a plain-JSON config without plugins
status line      model | dir branch (* = dirty) | context bar (green <50%, yellow <80%, red) | session cost | lines +/-;
                 plan limits shown only from 50%
no prompt        read-only git/gh, cargo fmt/tree, ls/cat/grep etc. (rg/fd/find/bat can run programs, so they still ask)

## git  (new defaults)
git pf           safe force push (--force-with-lease: refuses if the remote has commits you haven't seen)
git p            first push of a new branch sets its upstream, no -u needed
git up / pull    auto-stash around the rebase; fetch prunes deleted remote branches
git br           branches sorted by last commit          git commit  shows the diff in the editor
git dft / dlog / dshow   difftastic syntax-aware diff (diff / log with patches / show)

## Updating
update           update everything: brew, oh-my-zsh, oh-my-tmux + tmux plugins (rebuilds thumbs), nvim plugins,
                 Mason tools, gh extensions, yazi, ccusage, vimrc; a failing step doesn't stop the rest
                 (update --help for usage)
